¿Los talleres para universidades tienen costo?

No. Los talleres para universidades y grupos de estudio son gratuitos. Escríbeme para coordinar la fecha.

¿Cómo pago un curso o una asesoría?

Por ahora con Yape: haz clic en “Inscribirme”, yapea el monto y envíame la constancia. Te confirmo y te envío el acceso.

¿Necesito saber programar para llevar tus cursos?

Para Python 101 no: empezamos desde cero. Para Python y Machine Learning te recomiendo tener bases de Python.

¿Puedo llevar un curso si no llego a las clases en vivo?

Sí. Tengo el curso de Python asíncrono con clases grabadas para que aprendas a tu ritmo.
